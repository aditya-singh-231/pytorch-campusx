# pytorch-campusx

1. "pytorch_training_pipeline_L4"  ----->  The model made in this project is made without using any of the 'NN' libraries provided by 'pytorch', neither any optimization was done. The accuracy is quite low, but the main goal of this project is to learn the 'pytorch-training-pipeline'. The dataset used in this project is the 'breast-cancer-detection' dataset

2. "pytorch_training_pipeline_improved_L5_2"  ------>  The model made in this project is same as that that of made in lecture 4, but in this I have used built_in loss fn, built in optimizer and built in activation fn and also used torch.optim module is used. The dataset used in this project is the 'breast-cancer-detection' dataset

3. "pytorch_training_pipeline_improved_L5_1" -------> The model made in this project is made on a random generated dataset of shape(10,5) and containers are used in it like 'Sequential'. Also in this I have made a neural network with hidden layers.
